# Feature map

Where the code and tests for each feature live. If a path listed here does not exist, that is a bug in this file.
Widgets are in `crates/ui-core/src/widgets/` (`widgets/` in the table below), and catalog examples are in `apps/demo/src/catalog/` (`catalog/` in the table below).

| Feature | Code | Tests | Run only this feature |
|---|---|---|---|
| Widget Tree, events, Hit Testing, Focus, incremental updates | `crates/ui-core/src/{tree,widget,event,invalidation}.rs` | `crates/ui-core/tests/tree.rs` | `cargo test -p noa-gpui-core --test tree` |
| Keyboard focus (scrolling keyboard-moved focus into view with `Widget::reveal`, focus scopes with Ctrl+Tab, escaping from parts that take Tab) and the audit that tabs through the whole demo | `reveal_focused` and `focus_out` in `crates/ui-core/src/tree.rs`, `widgets/scroll_view.rs`, `widgets/terminal.rs` | `crates/ui-core/tests/{layout,desktop,terminal}.rs`, `the_keyboard_reaches_every_control_and_sees_it` in `catalog/mod.rs` | `cargo test -p noa-gpui-core --test layout keyboard_focus` |
| Crate dependency direction; `noa-gpui-core` and below independent of GPU and windowing | Each crate's `Cargo.toml` | `crates/ui-core/tests/architecture.rs` | `cargo test -p noa-gpui-core --test architecture` |
| Accessibility tree, names for assistive technology (`UiTree::set_accessible_label`, `labelled_by` on `FormField`), and the audit for unnamed controls in the demo | `accessibility_update` in `crates/ui-core/src/tree.rs`, `fn accessibility` in each `widgets/*.rs`, `apps/demo/src/a11y_audit.rs` | `crates/ui-core/tests/tree.rs`, `every_control_has_an_accessible_name` in `catalog/mod.rs` and `apps/demo/src/mini_os/mod.rs` | `cargo test -p demo --features demo/native every_control_has_an_accessible_name` |
| Web accessibility (the AccessKit tree mirrored as ARIA elements inside the canvas) | `crates/ui-platform/src/{web_aria,web_a11y}.rs` | `#[cfg(test)]` in `crates/ui-platform/src/web_aria.rs` | `cargo test -p noa-gpui-platform web_aria` |
| Pointer shape (`Widget::cursor` / `UiTree::cursor`, and each part's I-beam and resize shapes) | `crates/ui-core/src/{event,tree}.rs`, `fn cursor` in each `widgets/*.rs`, `sync_cursor` in `crates/ui-platform/src/app.rs` | `crates/ui-core/tests/cursor.rs` | `cargo test -p noa-gpui-core --test cursor` |
| Theme, animation, shortcuts, clipboard, overlays | `crates/ui-core/src/{theme,animation,shortcut,clipboard,overlay}.rs` | `#[cfg(test)]` in each file except `clipboard.rs` | `cargo test -p noa-gpui-core --lib` |
| CSS-like styling (parser, selectors, cascade, inheritance, `@media`, applying to Widgets; the box drawn for any Widget, the bezel and text of text inputs) | `crates/ui-core/src/styling.rs`, `crates/ui-core/src/{tree,widget}.rs`, `widgets/{container,label,button,editable,text_field,fields,text_area,text_view}.rs`, `docs/styling.md` | `crates/ui-core/tests/styling.rs`, `#[cfg(test)]` in `styling.rs` | `cargo test -p noa-gpui-core --test styling` |
| Loading style sheets from files and reloading on save (`StyleSheetWatcher`, `App::watch_stylesheet`, the demo's `--stylesheet`) | `crates/ui-platform/src/{stylesheet,app}.rs`, `apps/demo/src/app.rs`, `apps/demo/styles/example.noa.css`, `apps/desktop/src/main.rs` | `#[cfg(test)]` in `crates/ui-platform/src/stylesheet.rs`, `#[cfg(test)]` in `apps/demo/src/app.rs` | `cargo test -p noa-gpui-platform --features native --lib stylesheet` |
| Saving and restoring view state (`UiTree::set_autosave_name`, `view_state`, `restore_view_state`, the text format of `ViewState`; `Widget::save_state` / `restore_state` for table column widths and order, SplitView, TabView, DisclosureGroup, OutlineView, ScrollView, and InnerWindow; on desktop `App::autosave_view_state` and `ViewStateFile`; the demo's `--view-state`) | `crates/ui-core/src/{view_state,tree,widget}.rs`, `widgets/{table,panes,outline,scroll_view,desktop}.rs`, `crates/ui-platform/src/{view_state,app}.rs`, `apps/desktop/src/main.rs` | `crates/ui-core/tests/view_state.rs`, `#[cfg(test)]` in `crates/ui-core/src/view_state.rs` and `crates/ui-platform/src/view_state.rs`, `the_catalog_reopens_*` and `windows_and_the_finder_come_back_*` in `catalog/mod.rs` and `apps/demo/src/mini_os/mod.rs` | `cargo test -p noa-gpui-core --test view_state` |
