## 発見・修正した不具合

| 不具合 | 見つけた時 | 修正 |
|---|---|---|
| 320px で 8px の横はみ出し | サイクル 2 | 実績表示がグリッド列を押し広げていた → `minmax(0, 1fr)` とモバイルでの折り返し |
| モバイルでコピーボタンがコードに重なる | サイクル 1 | コードに名前のバーを付け、ボタンをコードの外へ |
| 1024px で見出しが句の途中で折れる | サイクル 2 | 1024px 以上で見出しのサイズを列幅に合わせた |
| モバイル TBT 350 ms（強制リフロー） | サイクル 3 | 初期化時のスクロール位置の読み取りを rAF へ |
| `dl` の構造違反、名前のない GitHub リンク | サイクル 3 | `dd` に変更、`aria-label` を追加 |
| フルページ撮影でセクションが空白、JS の失敗で全体が透明 | サイクル 3（独立レビュー） | `content-visibility` を削除し、2.5 秒後に表示する保険を追加 |

## 未検証の項目と理由

| 項目 | 理由 |
|---|---|
| Safari・Firefox・実機のスマホ | 利用できたのは Chromium だけ |
| 外部リンク（GitHub）の到達性、リポジトリの公開状態 | サンドボックスから GitHub に接続できなかった |
| OGP のプレビュー表示 | 公開 URL がなく、`og:image` は相対パスのまま |
| INP（実ユーザー） | 未公開のため実ユーザーのデータがない |
| Windows の表示（游ゴシック・メイリオで代替したときの和文の改行） | macOS でだけ確認 |
| 高コントラストモード（`forced-colors`） | CSS で対応したが、表示は確認していない |
