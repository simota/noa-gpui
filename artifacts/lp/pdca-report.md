# PDCA レポート

評価基準（100 点満点）: ファーストビュー 20、価値の伝わりやすさ 20、CTA 15、デザイン 15、レスポンシブ 10、UX・信頼性・アクセシビリティ 10、パフォーマンス・SEO・技術品質 10。

毎サイクル、Playwright（Chromium）で 320 / 375 / 768 / 1024 / 1440 / 1920px を撮影した。375px と 1440px はフルページも撮り、画像を目視で確認した。画像は `screenshots/iterations/cycle-N/` にある。

### 90 点に届かなかった理由（頭打ちの要因）

いずれも LP の作り込みでは解消できず、プロダクトや運用側の判断が要る。

1. **ブラウザで試せるデモがない。** `apps/web` は WebGPU / WebGL2 版をビルドできるが、この環境には `wasm-bindgen` がなく、公開先もない。公開すれば、主 CTA を「ブラウザでミニ OS を触る」に変えられ、CTA とファーストビューの点数が最も上がる
2. **他の選択肢との比較データがない。** バイナリサイズやメモリなどの実測がない。根拠なしに比較表は作らなかった
3. **公開 URL が未定。** `og:image`、`og:url`、canonical を絶対 URL にできない
