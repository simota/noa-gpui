# クリエイティブ戦略

## コンセプト：「本物の描画で語る」

LP に載せる製品画像は、すべて noa-gpui 自身の Headless レンダラーで描いた実際の出力にする。生成画像や架空の UI は使わない。開発者向けプロダクトでは「本物かどうか」が信頼の大半を占めるため、画像そのものを証拠として扱う。

比較したコンセプト:

| 案 | 内容 | 判断 |
|---|---|---|
| A. 性能を前面に | 「0.013 ms」を見出しに | 数字だけでは何の製品か伝わらない。性能は第 2 層の証拠に回した |
| B. 抽象的なブランドアート | 画像生成で GPU・光のビジュアル | 「AI が作った LP」に見え、本物の UI を見せる機会を失う。不採用 |
| **C. 本物の描画 + 明快な定義文**（採用） | 記憶に残る短い見出しと、製品カテゴリを言い切る太字の 1 文、実画面 | 何か・誰向けか・何が違うかを数秒で伝えられる |

## コアメッセージ

- 見出し: **Rust で書いて、GPU で描く。**
- 定義文（太字）: **Windows・macOS・Linux・Web で同じコードが動く、Rust 製の UI フレームワーク。**
- 補足: テーブルやターミナル、コマンドパレットまで揃った部品を、WebView を使わずに GPU が直接描きます。

サイクル 1 では見出しと「揃った部品」の文だけで、製品カテゴリ（UI フレームワーク）が小さなアイブロウにしかなかった。サイクル 2 で定義文を太字で独立させた。

## コピーの方針

- 機能名より「何を諦めずに済むか」を書く（軽さ・部品・見えない必需品）
- 数値には必ず条件と出典を添える（M1 Pro、p95、docs/architecture.md へのリンク）
- 制約（Web の IME 未対応、iOS/Android 非対応、crates.io 未公開）は FAQ で先に言う。隠すと導入後の不信につながる
- 競合製品名は出さない。比較の根拠となる測定がないため
- 「5 分で」などの検証していない所要時間は書かない（初回ビルドは wgpu などのコンパイルに時間がかかる）

## コンバージョン目標

| 優先 | 行動 | 導線 |
|---|---|---|
| 主 | サンプルを手元で動かす | ヒーローの「3 ステップで動かす」→ `#start`。コマンドはコピーボタン付き |
| 副 | GitHub でソースを見る（Star・Watch） | ヘッダー、ヒーロー、最終 CTA、フッター |
| 補助 | 仕組み・性能の出典を読む | docs へのリンク |

登録・問い合わせ・決済はプロダクトに存在しないため、作っていない。

## セクション構成と役割

1. **Hero** — 何か（定義文）、証拠（実画面）、主 CTA、3 つの実績値
2. **対応環境の帯** — 4 OS と GPU バックエンドを一目で
3. **課題** — 軽さ・部品・見えない必需品の三択を言語化し、「描画だけを自前で」という答え
4. **部品** — UI カタログの実画面と、グループ索引
5. **デザイン** — 7 デザイン × ライト／ダークを実描画で切り替える体験、Noa Style
6. **性能**（濃色） — 出典付きの 3 つの数値
7. **見えない必需品** — IME、a11y、キーボード、状態保存、OS 統合、Headless
8. **仕組み** — クレートの層構成図
9. **始め方** — サンプル実行 → コードを読む → 自分のアプリに入れる
10. **FAQ** — 対応環境、Web の制約、導入方法、ライセンス、カスタマイズ、品質の担保
11. **最終 CTA** — ミニ OS を動かすコマンド
12. **Footer** — ドキュメントとプロジェクトへのリンク、画像の出所の明記

「導入事例」「レビュー」のセクションは、確認できる情報がないため作っていない。代わりに測定値・テスト・実画面を信頼の根拠にした。

## デザインの意図

- **色:** プロダクト自身のテーマから取った。紙色 `#f4f5f8`（Big Sur ライトの背景）、インク `#12141b`、アンバー `#e8a33d`（`theme.rs` の `NOA_ACCENT`）。ブランド色をプロダクト内のデザイン「Noa」と一致させた
- **背景の 32px グリッド:** レンダラーが重なり判定に使う 32 論理 px の一様グリッドから。装飾ではなく仕組みへの目配せ
- **カードの連続を避ける:** 課題・必需品・FAQ は罫線と余白で区切り、カードは実画面の額縁と層構成図だけに使う
